# beerline

Адаптивний лендинг українською без залежностей.

## Запуск

Відкрийте `index.html` у браузері або розмістіть `index.html`, `styles.css` і `script.js` в одній папці на статичному хостингу.

## Перед публікацією

- У `script.js` додайте справжній номер у `CONTACT_PHONE` в міжнародному форматі: `+380…`. Кнопка «Зателефонувати» відкриє дзвінок через `tel:`. До додавання номера вона показує повідомлення про його відсутність.
- Додайте адресу, графік роботи та видимий номер телефону в контактах `index.html`.
- Замініть ілюстративні категорії меню актуальним асортиментом і цінами.
- Додайте справжні відгуки гостей за їхньою згодою.

Фільтри меню, FAQ і навігація працюють локально. Сервер не потрібен.
